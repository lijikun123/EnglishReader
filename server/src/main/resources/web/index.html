启用 AI 精读

为了保护百炼 API Key，网页不会让你填写或保存 Key。请只在 VPS 上配置，网页会自动读取可用状态。

  1. 通过 SSH 登录 VPS，进入 /opt/kreader-sync/deploy。
  2. 在受保护的 .env 中添加以下配置；不要把 Key 发到聊天、提交到 GitHub 或填进网页。
DASHSCOPE_API_KEY=你的百炼_API_Key
KREADER_AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
KREADER_AI_MODEL=qwen-plus
  1. 在同一目录执行：
docker compose up -d --no-deps --force-recreate api

以上默认地址适用于北京地域；如果百炼控制台给了业务空间或其他地域的专属地址，请使用控制台显示的完整 Base URL。Key 和地域必须匹配。
